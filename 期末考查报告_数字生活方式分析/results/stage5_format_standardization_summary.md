# Stage 5 格式规范化重构总结

## 1. 本次修改范围

本次只对 `overleaf_final/` 中的 LaTeX 报告结构、章节组织、表格显示和 PDF 编译包进行格式规范化重构。

未新增实验，未重跑分类、回归、聚类主模型，未修改 `results/*.csv` 中任何核心指标。

## 2. 结构规范化内容

- 将报告由“评分点式实验报告”重构为课程设计/论文式结构。
- 使用 `ctexrep` 和 `\chapter` 组织一级章节。
- 正文结构调整为：引言、相关理论与方法基础、数据集与预处理、方法设计与实验实现、实验结果与分析、总结与展望。
- 将参考资料与数据来源移出附录，独立为“参考文献”。
- 将附录规范为：
  - 附录 A 核心代码；
  - 附录 B 个人完成情况与独立性说明；
  - 附录 C 项目链接与运行说明；
  - 附录 D 补充图表与完整结果文件说明。
- 保留《大数据分析与应用》课程考查报告封面模板，未改成其他课程设计封面。

## 3. 借鉴的格式优点

本次仅借鉴课程设计/论文式报告的结构优点，包括：

- 先给出理论与方法基础，再展开实验实现；
- 将方法设计与实验结果分章呈现；
- 将参考文献独立成节；
- 将完整代码和补充图表放入附录；
- 使用按章编号的图表编号，提升目录和引用的规范性。

未复制人工智能课程设计报告的正文内容。

## 4. 核心结论保持情况

核心实验结论保持不变：

- 分类任务仍采用 Gradient Boosting + threshold=0.14 的偏召回筛查策略；
- `digital_dependence_score` 仍作为回归主线；
- `productivity_score` 仍作为弱预测/负结果分析；
- KMeans `k=3` 的 Silhouette=0.1860，聚类仍解释为探索性画像；
- 报告继续强调合成数据限制，不作医学诊断或因果化结论。
