\chapter{个人完成情况与独立性说明}

本项目围绕《大数据分析与应用》课程考查要求独立完成，未复制旧实验报告内容。个人完成情况包括：

\begin{itemize}
  \item 完成数据集筛选，比较课程要求、数据来源、发布时间、CSV 格式、样本规模和任务适配性。
  \item 设计分类、回归和聚类三类实验方案，并明确不使用深度学习和 GPU。
  \item 编写 Python 代码完成数据读取、预处理、工程特征、EDA、分类、回归、聚类、PCA 和结果汇总。
  \item 对分类任务进行目标泄漏控制、超参数调优和阈值选择。
  \item 对回归任务分别报告数字依赖强预测和生产力弱预测结果。
  \item 对聚类任务控制输入特征范围，并将聚类结果解释为探索性画像。
  \item 整理 results、figures、report/tables 和 overleaf\_final 编译包，完成 LaTeX 正式报告写作与格式规范化。
\end{itemize}

报告中的指标均来自已运行生成的结果文件，不编造未运行实验结论。对模型不能支持的部分，例如生产力得分弱预测和聚类边界较弱，也在正文中如实说明。
