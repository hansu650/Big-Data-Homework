\section{讨论}

本节将在真实实验结果生成后补充，重点讨论模型表现、关键行为变量、聚类画像含义、目标泄漏控制以及方法局限。

\subsection{待补充问题}

\begin{itemize}
  \item 分类模型是否能在排除心理与效率结果变量后仍有效识别高风险用户？
  \item 阈值调优后，高风险筛查应优先选择哪个 Recall/F1 权衡点？
  \item 数字依赖程度的预测主要依赖哪些数字行为或生活习惯变量？
  \item \texttt{digital\_dependence\_score} 是否比 \texttt{productivity\_score} 更适合作为回归主线？
  \item 聚类得到的用户画像是否能解释不同风险、数字依赖与效率水平？
  \item 聚类轮廓系数若偏低，报告应如何限制画像解释范围？
\end{itemize}
