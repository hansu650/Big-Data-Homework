\section{聚类实验：数字生活方式用户画像分析}

\subsection{任务设定}

聚类任务仅使用数字行为与生活习惯数值变量，不使用人口背景类别变量、设备类别变量、高风险标签、数字依赖分数或效率结果变量。聚类完成后，再将 \texttt{daily\_role}、\texttt{device\_type}、\texttt{high\_risk\_flag}、\texttt{digital\_dependence\_score}、\texttt{productivity\_score} 等变量用于画像解释。

\subsection{模型与指标}

使用 KMeans 对 $k=2$ 到 $k=8$ 进行肘部法则和轮廓系数分析，并补充 AgglomerativeClustering 与 GaussianMixture 的算法对比。评价指标包括 Silhouette、Calinski-Harabasz、Davies-Bouldin 与 KMeans Inertia。
