\section{分类实验：高风险用户预测}

\subsection{任务设定}

分类目标为 \texttt{high\_risk\_flag}。模型输入排除全部指定泄漏列，并使用训练集/测试集划分评估模型泛化表现。

\subsection{模型、调参与指标}

模型包括 Logistic Regression、Random Forest 和 Gradient Boosting。第二阶段补充 GridSearchCV/RandomizedSearchCV 调参，评价指标包括 Accuracy、Precision、Recall、F1、Balanced Accuracy、ROC-AUC 与 PR-AUC。
