\section{代码与复现实验说明}

核心代码位于 \texttt{src/} 目录，实验 notebook 位于 \texttt{notebooks/} 目录。

\begin{itemize}
  \item \texttt{src/config.py}：路径、随机种子、目标变量与泄漏列配置。
  \item \texttt{src/data\_utils.py}：数据下载、读取、合规检查和摘要输出。
  \item \texttt{src/feature\_engineering.py}：特征工程、特征排除规则和预处理管道。
  \item \texttt{src/model\_utils.py}：分类、回归与聚类实验函数。
  \item \texttt{src/visualization.py}：EDA、模型结果与聚类图表绘制函数。
\end{itemize}

复现实验时按 README 中的 notebook 顺序执行即可。
